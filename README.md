# JS Modules Practice

## export / import vs module.exports / require

ES Modules use `export` and `import`, which are statically analyzed and support top-level syntax. In contrast, CommonJS uses `module.exports` and `require`, which are dynamic and more flexible but less optimized for modern tooling.

## Why choose ES Modules for modern Node projects?

ES Modules align with browser JavaScript standards, improve tooling compatibility, and are the future default in Node.js development.
